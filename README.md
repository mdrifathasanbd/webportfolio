# Rifat Hasan Portfolio HTML Website

A responsive HTML/CSS/JS recreation of the chosen portfolio landing-page direction.

## Files
- `index.html` — website markup
- `style.css` — responsive styling and motion
- `script.js` — portfolio slider, mobile menu, scroll reveals
- `assets/` — local visual assets

## Notes
- Portfolio cards use CSS scroll-snap and lightweight JavaScript instead of a heavy slider library.
- Motion respects `prefers-reduced-motion`.
- Mobile layout is independently optimised rather than just scaled down.
- Replace project images, text, email, and links directly in `index.html`.
- This static version can later be mapped section-by-section into Elementor widgets / XPro Theme Builder.
