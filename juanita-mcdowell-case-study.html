WordPress Redesign That Books Clients

MY ROLE Website Designer

PROJECT OVERVIEW

From three core pages to a complete website refresh.

I partnered with the client and her branding specialist to translate refreshed messaging and brand assets into a modern, high-impact WordPress website.

The project originally started as a redesign of three key pages: Home, About, and Keynote.

As the project progressed, it expanded into a complete website refresh covering the overall visual experience, mobile responsiveness, performance optimisation, navigation, and usability.

The goal was to create a website that better represented the client's professional brand while making it easier for visitors to explore her services, speaking information, resources, and booking opportunities.

HomeAboutKeynote
OBJECTIVES

What the website refresh needed to improve.

  • Modernise the website's visual design and typography
  • Integrate the client's new messaging, copy, and brand assets
  • Improve the overall user experience
  • Ensure proper responsiveness across desktop, tablet/iPad, and mobile
  • Improve website loading speed
  • Resolve existing UI and layout issues
  • Simplify navigation
  • Make important booking and resource information easier to access
  • Improve the overall technical quality of the WordPress website
RESPONSIVE OPTIMISATION

Responsive across desktop, tablet, and mobile.

The website was refined across screen sizes so the refreshed brand, navigation, content presentation, and usability remained consistent from desktop through tablet and mobile.
